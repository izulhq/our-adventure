# React Leaflet × Google Spreadsheet

![Interactive Adventure Map](public/cover.png)

## what the fuck is this (?!)

Basically, this is our little interactive adventure map.

Whenever and wherever we go, we collect places, coordinates, names, descriptions, and addresses — all stored neatly in a Google Spreadsheet. The data is then automatically displayed on this map, so we can easily keep track of everywhere we've been.

We also have a wishlist for places we want to visit next, pulled directly from the same spreadsheet. Add a place to the sheet, and it magically appears on the map. ✨

Simple, interactive, and easy to update.
